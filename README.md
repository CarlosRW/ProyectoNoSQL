
# Sistema de Gestión y Análisis Transaccional - Rolvin Tours

Aplicación web analítica y transaccional diseñada para centralizar las operaciones operativas y financieras de la empresa de turismo marino **Rolvin Tours** (Cóbano, Puntarenas). Proyecto desarrollado para la Facultad de Ingeniería en Sistemas de Computación, Universidad Fidélitas.

## 🛠️ Stack Tecnológico (MERN)

* **Backend:** Node.js, Express
